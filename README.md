# 📸 Photobooth Application

A desktop application built with **PyQt5** and **OpenCV** that lets users capture photos with countdowns, apply filters, preview images, and manage a personal photo gallery.

---

## 📖 Overview

This Photobooth app simulates a fun photo-taking experience with a clean UI and powerful features. It includes a live webcam feed, countdown timer, gallery management, and dark/light mode switching for a customizable experience.

---

## 🛠️ Tech Stack

* **Python**
* **PyQt5** (for UI)
* **OpenCV** (for webcam & image processing)
* **OS / File Handling** (for saving & managing images)

---

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/photobooth-app.git
cd photobooth-app
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python photobooth.py
```

---

## 📸 Features

* ✅ Live webcam feed
* ✅ Countdown timer before capture
* ✅ Grayscale filter support
* ✅ Save photos with custom names or timestamps
* ✅ Dark/Light mode toggle
* ✅ Thumbnail previews with click-to-open full image
* ✅ Gallery view with slideshow and delete functionality
